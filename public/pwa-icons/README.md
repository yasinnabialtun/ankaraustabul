# PWA Icons

This directory contains the Progressive Web App (PWA) icons that are used by the app when installed on a device.

## Required Icons

- `pwa-192x192.png` - Icon used on Android devices
- `pwa-512x512.png` - Large icon used on various devices
- `apple-touch-icon.png` - 180x180 icon used on iOS devices

## Usage

These icons are referenced in the PWA manifest file and are automatically included during the build process.
